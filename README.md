# tempfed

**tempfed** is a temporary caching server for the Fediverse and Social Web.

## Motivation

Traditionally, the most common cause for why a Fediverse or Social Web server crashed is
—
its storage drive fills up with data from other servers (typically for caching purposes).
This data from other servers includes:
posts,
media,
profile data,
avatar images,
header images,
etc.
